# Security Policy

## Supported versions

Only the latest release on the [Releases page](https://github.com/savan5685k-beep/DUO-Tube/releases) receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/savan5685k-beep/DUO-Tube/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. The maintainers will review reports and coordinate fixes through the private advisory.

## Scope

In scope: the Android app in this repository, its build and release pipeline.
Out of scope: third-party websites, the yt-dlp and NewPipe projects (report to them directly), and issues that need a rooted
or already-compromised device.
